前言

「启明星」（英文名 Venus）是一款由个人开发者 MuxiaoWF 开发并维护的 Android 应用，用于自动化执行米游社 / HoYoLAB 与《森空岛》的日常签到任务，并辅助获取游戏抽卡记录链接。

我们最重要的承诺：本应用不运营任何用户服务器，不建立自有账号体系，你的一切数据都保存在你自己的设备中。我们看不到、也拿不到你的任何个人数据。

本政策详细说明本应用处理数据的方式。使用前请仔细阅读；继续使用即表示你已理解并同意本政策。

一、我们处理哪些数据

1.1 账号凭据（由你主动提供）

添加账号时，本应用会从米游社 / HoYoLAB 官方接口获取并在本地保存以下登录凭据：

数据项说明用途
stoken / ltoken / cookie_token米游社登录态令牌调用签到、任务、抽卡链接接口
mid / account_id米游社账号标识标识当前操作的账号
login_ticket / game_token临时票据登录态换取
cookie完整的登录 Cookie 字符串请求鉴权
  • 存储位置：设备本地，应用私有 SharedPreferences（MODE_PRIVATE）。受 Android 应用沙箱保护，其他应用无权访问。
  • 是否上传给我们：否。这些凭据仅在请求米游社 / HoYoLAB 官方接口时作为鉴权信息发送，不会发送给本应用开发者或任何第三方服务商。
关于密码：国服「账号密码登录」功能中，你输入的密码会在设备本地使用米游社 1024 位 RSA 公钥加密，再发送至米游社官方登录接口（passport-api.mihoyo.com）。本应用不会以明文或密文形式保存你的密码，登录成功后仅保留上表中的令牌。

1.2 设备信息（用于接口签名与设备指纹）

米游社 / HoYoLAB 接口要求请求方提供设备指纹（device_fp）与签名参数，因此本应用会读取并向米游社 / HoYoLAB 官方服务器发送以下设备信息：

  • 设备标识符：OAID（开放匿名设备标识符）；若获取失败，则使用由 Android ID 与设备厂商 / 型号在本地生成的稳定 UUID。我们不读取 IMEI、MEID、MAC 地址，也不使用广告标识符（AAID / GAID）。
  • 设备特征：设备型号、制造商、品牌、硬件名称、产品名称、主板、CPU 架构（ABI）、屏幕分辨率、系统版本、ROM 与 RAM 的总容量及剩余容量、系统构建信息（TAGS / DISPLAY / TIME / USER / TYPE / HOST / BOARD）。
  • 序列号：固定发送 UNKNOWN，我们不上报设备的真实序列号。
  • 传感器数据：加速度计、磁力计、陀螺仪字段为固定占位值，并非真实读数。

用途：向米游社设备指纹接口换取 device_fp、生成接口 DS 签名，以完成官方接口的正常鉴权流程。
接收方：米游社 / HoYoLAB 官方服务器（如 fp-it.portal101.cn）。

1.3 应用运行日志

签到任务的执行日志会写入本应用的私有外部存储目录（Android/data/com.muxiao.Venus/files/logs/）。日志仅保存在设备本地，不会自动上传，仅在你主动导出时由你自己处理。

提示：日志可能包含接口返回的错误信息。分享日志前请自行检查并删除其中的个人内容。

1.4 我们不收集的数据

本应用不收集以下任何数据：

  • 精确或大致位置信息
  • 通讯录、短信、通话记录
  • 相机、麦克风采集的影像与音频
  • 日历、健康与健身数据
  • 应用使用行为分析、页面埋点、用户画像
  • 崩溃报告与性能诊断数据（本应用未集成任何崩溃上报 SDK）
  • 广告标识符 —— 我们已在清单文件中显式移除 AD_ID、READ_PHONE_STATE 等权限

三、系统权限说明

权限用途是否必需
INTERNET访问米游社 / HoYoLAB 接口、检查更新必需
ACCESS_NETWORK_STATE判断网络可用性，避免无网时执行任务必需
READ_EXTERNAL_STORAGE（仅 Android 12L / API 32 及以下）读取你选择的背景图片可选
POST_NOTIFICATIONS显示后台签到任务进度通知可选
FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC后台执行签到任务可选
WAKE_LOCK防止后台任务执行期间设备休眠可选

所有权限均可在系统设置中随时撤销；撤销「可选」权限仅影响对应功能，不影响应用基本运行。

四、数据会发送给谁

除以下情况外，你的数据不会离开你的设备：

接收方目的发送的数据
米游社 / HoYoLAB（米哈游 / HoYoverse）
*.mihoyo.com、*.miyoushe.com、*.hoyoverse.com、*.hoyolab.com、fp-it.portal101.cn		签到、获取抽卡链接、设备指纹、验证码账号凭据 + 1.2 节设备信息
森空岛（鹰角网络）
*.skland.com、as.hypergryph.com		《森空岛》签到森空岛账号凭据与必要设备信息

我们不会出售、出租或以任何形式向第三方共享你的个人数据用于广告或营销目的。

五、数据保留与删除

  • 保留期限：账号凭据与本地配置会一直保留，直到你主动删除为止。
  • 删除方式（任选其一）：
    1. 在应用内「用户管理」页面删除对应账号 —— 立即移除该账号的全部凭据；
    2. 系统「设置 → 应用 → 启明星 → 存储 → 清除数据」—— 清除全部本地数据；
    3. 卸载应用 —— 清除全部本地数据。
  • 我们无服务器端数据：本应用不运营用户服务器，因此不存在需要我们代为删除的云端数据副本。若你对数据删除有任何疑问，可按文末方式联系我们。

六、数据安全

  • 凭据保存在应用私有目录中，受 Android 应用沙箱保护，其他应用无法直接读取。
  • 所有网络请求均通过 HTTPS 加密传输，应用已通过网络安全性配置（Network Security Config）禁用明文流量。
  • 密码在设备本地使用 RSA 公钥加密后再传输，本地不留存。
风险提示（请务必阅读）
  • 本应用保存的令牌具备对应米游社 / HoYoLAB 账号的操作权限，请勿在已 root 或安装了不可信应用的设备上使用。
  • 应用清单中 allowBackup 为开启状态。若你启用了系统备份（如 Google 云端备份），本地数据可能随备份一并存储到你的备份空间中。你可以关闭该设备的备份功能，或先在「用户管理」中删除敏感账号再执行备份。
  • 请通过官方渠道获取安装包，避免使用来路不明的修改版。

七、儿童隐私

本应用不面向 13 岁以下儿童，也不会在知情的情况下收集儿童的个人信息。若你是监护人并发现儿童向我们提供了信息，请按文末方式联系我们，我们会协助删除相关数据。

八、第三方服务的隐私政策

本应用所对接的米游社 / HoYoLAB、《森空岛》等服务的账号与数据处理，遵循其各自运营方（米哈游 / HoYoverse、鹰角网络）的隐私政策。本政策不涉及、也无法约束这些第三方服务的行为，请你在使用前自行查阅：

  • 米哈游 / HoYoverse：《米游社用户协议》与《隐私政策》
  • 鹰角网络：《森空岛用户协议》与《隐私政策》
  • 极验：《极验隐私政策》
