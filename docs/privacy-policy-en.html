Introduction

Venus (Chinese name 启明星) is an Android app developed and maintained by an independent developer, MuxiaoWF. It automates daily check-in tasks for MiYouShe / HoYoLAB and Skland (森空岛), and helps retrieve in-game gacha record links.

Our core commitment: this app operates no user-facing server and maintains no account system of its own. All of your data stays on your own device. We cannot see and do not receive any of your personal data.

This policy explains in detail how the app handles data. Please read it carefully before use. Continued use means you have read and understood this policy.

1. Data we process

1.1 Account credentials (provided by you)

When you add an account, the app obtains the following login credentials from the official MiYouShe / HoYoLAB endpoints and stores them locally:

ItemDescriptionPurpose
stoken / ltoken / cookie_tokenMiYouShe session tokensCalling check-in, task, and gacha-link endpoints
mid / account_idMiYouShe account identifiersIdentifying the account being operated on
login_ticket / game_tokenTemporary ticketsExchanging login state
cookieFull login cookie stringRequest authentication
  • Where it is stored: locally on your device, in app-private SharedPreferences (MODE_PRIVATE), protected by the Android app sandbox so that no other app can access it.
  • Is it uploaded to us: No. These credentials are sent only as authentication data to the official MiYouShe / HoYoLAB endpoints. They are never sent to the app developer or to any third-party service provider.
About passwords: in the CN-region “password login” flow, the password you type is encrypted on your device using MiYouShe's 1024-bit RSA public key and then sent to the official login endpoint (passport-api.mihoyo.com). The app does not store your password in any form, neither plaintext nor encrypted. After a successful login, only the tokens listed above are retained.

1.2 Device information (used for request signing and device fingerprinting)

The MiYouShe / HoYoLAB API requires callers to supply a device fingerprint (device_fp) and signature parameters. For this reason, the app reads and transmits the following device information to the official MiYouShe / HoYoLAB servers:

  • Device identifier: OAID (Open Anonymous Device Identifier). If OAID retrieval fails, a stable UUID is generated locally from the Android ID combined with the device manufacturer and model. We do not read IMEI, MEID, or MAC addresses, and we do not use any advertising identifier (AAID / GAID).
  • Device characteristics: device model, manufacturer, brand, hardware name, product name, board, CPU architecture (ABI), screen resolution, OS version, total and remaining ROM and RAM capacity, and build information (TAGS, DISPLAY, TIME, USER, TYPE, HOST, BOARD).
  • Serial number: the value UNKNOWN is always sent. We do not transmit your device's real serial number.
  • Sensor data: accelerometer, magnetometer, and gyroscope fields are fixed placeholder values, not real readings.

Purpose: to obtain a device_fp from the MiYouShe fingerprint endpoint and to generate the DS request signature required by the official API.
Recipient: official MiYouShe / HoYoLAB servers (e.g. fp-it.portal101.cn).

1.3 App run logs

Execution logs for check-in tasks are written to the app's private external storage directory (Android/data/com.muxiao.Venus/files/logs/). Logs are stored locally only and are never uploaded automatically; they leave the device only if you choose to export them yourself.

Note: logs may contain error information returned by API endpoints. Please review and remove any personal content before sharing logs.

1.4 Data we do not collect

The app does not collect any of the following:

  • Precise or approximate location
  • Contacts, SMS messages, or call logs
  • Images or audio captured by the camera or microphone
  • Calendar, health, or fitness data
  • In-app usage analytics, event tracking, or user profiling
  • Crash reports or performance diagnostics (the app integrates no crash-reporting SDK)
  • Advertising identifiers — the AD_ID and READ_PHONE_STATE permissions have been explicitly removed from the app manifest

5. Retention and deletion

  • Retention period: account credentials and local settings are kept until you delete them.
  • How to delete (choose any one):
    1. Delete the account on the in-app “User management” screen — removes all credentials for that account immediately;
    2. System “Settings → Apps → Venus → Storage → Clear data” — removes all local data;
    3. Uninstall the app — removes all local data.
  • We hold no server-side data: because the app operates no user server, there is no cloud copy for us to delete on your behalf. If you have questions about data deletion, contact us using the details below.

6. Data security

  • Credentials are stored in the app's private directory, protected by the Android app sandbox so other apps cannot read them directly.
  • All network traffic is encrypted over HTTPS; cleartext traffic is disabled through the Network Security Configuration.
  • Passwords are encrypted on-device with an RSA public key before transmission and are never stored locally.
Risk notices (please read)
  • The tokens stored by this app grant operational access to the corresponding MiYouShe / HoYoLAB account. Do not use the app on a rooted device or one with untrusted apps installed.
  • allowBackup is enabled in the app manifest. If system backup (for example, Google backup) is turned on, local data may be included in your backup. You can disable backup for that device, or delete sensitive accounts in “User management” before backing up.
  • Obtain the app only from official channels and avoid modified packages from unknown sources.

7. Children's privacy
